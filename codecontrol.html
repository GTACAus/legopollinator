01/03

Change the way your robot pollinator moves

You can program your pollinator with code blocks on the iPad. Each button on the remote makes it move in a different way. Try it out!

◀ Home

02/03

Open the code canvas

Each button on the d-pad moves the robot forward, backward, left or right. The slider controls the robot's pollination arm.

  1. Connect your iPad to the robot's Wi-Fi (see the robot pollinator steps).
  2. On the remote, choose Advanced (code), then tap </> Code.
  3. The starting program is already there: each control turns at least one motor.
  4. Tap ▶ Run, then use the remote on the right to test it.

03/03

Change your code

  1. Tap a number in a move block and change it: 3 cm is a small move forward, 15 is half a ruler.
  2. Drag set movement speed to slow / medium / fast from Movement to change how fast it moves (or set Motor speed from Motors for the arm).
  3. Try go to position to send a motor to an exact angle.
  4. Tap ■ Stop, then ▶ Run again to try your changes. Your code is saved on the iPad.

Stuck? Tap the yellow ? in the app for help.
